# Demonstração Vercel — 21/10/2026

O Preview do projeto `tavvo-demo` foi compilado e validado com os serviços
Vite, Django e Next.js na Vercel, usando PostgreSQL e armazenamento S3 reais
do Supabase Free. O fluxo testado percorreu navegador, API, banco e resposta
pública, sem interceptar as APIs no Playwright.

O banco usa uma role runtime sem superusuário, propriedade das tabelas ou
`BYPASSRLS`. As migrações usam uma conexão administrativa separada, mantida
localmente. O schema da aplicação não fica disponível pelo Data API do Supabase,
e o bucket de imagens é privado. Credenciais, cookies e links de acesso não
fazem parte desta evidência versionada.

## Reprodução e limites

O [runbook de demonstração](../runbooks/vercel-demo.md) descreve provisionamento,
variáveis de ambiente, seed e testes. As instruções de acesso e a conta do gestor
ficam em `.local/acesso-demo.md`, ignorado pelo Git e pelo upload para Vercel.

Este resultado confirma uma demonstração funcional do MVP. Recuperação por
e-mail está indisponível, imagens estão limitadas a 4 MiB e os recursos usam
planos gratuitos. SMTP externo, ensaio de restauração, monitoramento operacional
e demais requisitos de produção continuam fora desta validação. Não houve
contratação de plano pago nem promoção deste Preview a produção.
